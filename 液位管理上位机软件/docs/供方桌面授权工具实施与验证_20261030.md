# 供方桌面授权工具（2026-10-30）

用户要求确认私钥位置，并把原命令行签发做成桌面工具。新增 `tools/LevelManager.LicenseDesk`，C# / Windows Forms，win-x64自包含，无WebView2或开发环境依赖。只供我方使用；客户运行程序及其授权格式不变。

- 工具ZIP：`output/供方桌面授权工具_20261030.zip`，51,671,521 bytes，SHA256 `63E5EA01CD15F6D11D8B932FBA78BCEDE777648F33A482ADDA8FAB23E5EB6D5B`。276项清单及ZIP CRC/SHA全部通过。
- 桌面快捷方式：`C:/Users/admin/Desktop/液位管理系统-供方授权工具.lnk`；已打开干净工具窗口，未载入真实客户请求。
- 私钥仍在 `.build-tools/vendor-keys/level-manager-signing.pem`；只用内存挑战签名验证匹配现有产品公钥，文件大小及修改时间不变。未移动、复制、改写或重新生成私钥；包内无密钥和客户授权文件。
- 使用说明：`deployment/vendor/桌面授权工具说明.html`，随工具附同内容HTML及原桌面图标同步脚本、.NET许可。

## 行为

1. 读取客户目标机请求，验证产品和64位安装编号；选择其他客户请求时清空旧客户品牌及模块。
2. 客户名称、期限（北京时间到秒或永久）、模块显式选择；平均测温默认未勾选，本次客户已要求开通，实际签发时必须勾选。
3. 可填写软件及厂家信息、Logo和图标；续期载入旧授权后验证签名/安装编号，保留品牌图像和模块，提出大于本地已知/载入旧授权的序号。
4. 最终摘要确认后才读私钥签发，使用现有ProductTrust公钥及LicenseVerifier复验，不提供换公钥、生成密钥、时钟修复入口。
5. 先持有签发目录文件锁，检查相同安装的历史签名记录和序号，再写不可覆盖记录，最后导出客户文件；导出失败保留签名记录并明确提示补发，不能误报未签发。
6. 不会自动推断其他电脑或旧CLI的全部签发历史，续期须提供客户当前最新授权。每次为整份授权，保留模块与品牌的责任在最终摘要明确。
7. 模块授权不会放开不支持的协议/现场条件：r12自动无线平均仍仅符合条件直连RTU开放，网关/IFX自动任务暂未放开；ATS实时平均与IR26瞬时温度区别沿用原程序。
