# ADR-007：直连普通动作取消远程状态位拦截

## 状态

2026-10-30后续用户扩大确认，已由[ADR-008](ADR-008-所有操作取消远程状态位拦截.md)取代；以下为r17时点记录。

已确认，2026-10-30。用户明确选择：“直连普通动作也取消；保留故障、权限、认证和回读检查”。r17实施。

## 背景

用户T-101的上升/下降记录走DirectRtu、COM3，并非网关。管理系统此前只按网关ADR-017取消GatewayTcp/GatewayRtu的IR51 bit15检查，直连普通动作仍被“仪表不在远程控制状态”拦截。

## 决策

- 手工直连RS-485 Modbus RTU普通动作不要求IR51 bit15为1，包括测量Ⅰ/Ⅱ/Ⅲ、上升、下降、远程密度、重复性检查、液体震荡回避；停止原机制保持。
- 保留有效且新鲜的液位/状态/故障数据、岗位权限、软件授权、按罐允许动作、HR129=0x10D9认证、审计与一次HR699写入、HR698及IR51/52回读。
- 保留原始状态字，不伪造远程位。去掉该前置位判断不保证仪表必然接受动作；拒绝和不匹配仍失败或未知，未知不自动重发。
- 本次没有扩大到IFX、自动平均测温任务（包括共用的已认证任务移动及自动恢复）、直连远程液位参数修改；这些原检查保持。
- 沿用r16串口空白/固定下拉及r15画面。schema16不变，原数据授权保持；不为修改旧记录自动补发动作。

## 验证与影响

旧实现8个普通非停止动作的远程位0用例失败，修复后18种动作/初始远程位组合通过，回读实际远程位仍0；故障/状态缺失/认证失败、回执丢失/回读不匹配、IFX和自动测温原条件亦覆盖。最终346项通过，证据见r17实施说明。

只对软件模拟进行了验证，真实串口与仪表由现场使用新后台版本复核。本轮不占用用户COM3、不更新正在运行的旧预览和长测，不修改网关工程或授权密钥。

## 依据

用户本轮明确确认；网关对同一仪表普通动作的既有模式独立策略（设备采集网关/decisions/ADR-017-取消IR51远程位控制门槛.md）。
