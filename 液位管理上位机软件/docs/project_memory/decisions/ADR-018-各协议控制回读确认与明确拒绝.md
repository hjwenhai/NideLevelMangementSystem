# ADR-018 各协议控制回读确认与明确拒绝

已确认并实施，2026-11-13。用户要求按各协议持续回读、明确拒绝分类、未知保留核查的建议实施，并询问超时时间。

## 处理规则

- IFX L25原先在完成握手后只读一次模式。改为在本次确认窗口内持续读取原始高度、模式及故障，目标模式匹配后自动结案。执行和完成标志必须经历本次握手，旧ON须先清除。
- IFX本次完成标志等待、完成后标志清零与模式回读共用ConfirmationTimeoutSeconds。新动作前的旧标志清理独立使用同一设定时限。读取按通道超时执行，因此极限耗时还包含当前在途读取与重试。
- 直连RTU及网关TCP/RTU继续持续回读。超时显示阶段、设定秒数、已等待秒数、期望模式与最后读取模式及原始状态，网关另记最后结果状态。
- 控制前置检查使用协议原始高度，表示当前浮子位置，独立于界面液面和库存有效性。故障和位置/模式数据有效性检查继续执行，停止保留优先处理。
- 仅在本次动作提交写入取得明确异常01/02/03/06时记Rejected。IFX写命令与触发执行线圈、直连命令写入、网关普通动作及远程液位提交均覆盖。完成后的清标志异常和通讯超时/应答丢失继续按不确定阶段处理，未知记录不自动重发动作。
- 故障检查在确认成功前执行。直连和IFX停止仍可在故障存在时尝试并回读模式。

## 超时及现场状态

新建罐默认回读30秒，允许3～300秒，入口为储罐配置/操作与温度/控制等待参数。当前本机14罐原配置实际均为5秒，升级没有改写。单次读取默认1000ms，默认读重试1次。测温移动默认600秒，允许30～3600秒。
