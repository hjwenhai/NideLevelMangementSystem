# ADR-019：一罐多仪表方案暂缓实施

## 状态

已确认：暂缓实施，仅保留讨论记录。确认日期：2026-11-13。

## 背景

客户反馈《系统问题反馈_20261111.docx》第1点提及一个储罐可能安装多个液位计。讨论总览改进时，提出若按仪表显示卡片，需要避免同一物理罐的库存重复汇总。

用户随后与客户确认：通常一个储罐只有一个液位计，一罐多液位计的情况极少，本阶段暂不考虑。用户明确要求记录讨论，但不实施。

## 决策

- 当前版本继续按“一罐一表”规划和实现。
- 本次不新增物理储罐与多仪表关联模型，不新增库存计算仪表选择、备用切换及相关权限/日志功能。
- 本次不因该讨论放开重复罐号或改变已有库存统计规则，也不将暂缓方案列为当前开发任务。
- 总览布局讨论图中的“所选范围仪表 / 全部仪表”等区分属于讨论示意，正式实施总览时应按当前一罐一表范围使用储罐数量口径，不据此引入多仪表功能。
- 将来确有现场需求时，重新确认数据模型、迁移、画面和统计规则后再实施。

## 留存的候选方案（未实施，非当前需求）

1. 每个物理储罐可关联多台仪表，以内部唯一标识关联，不仅凭重复罐号判断同罐。
2. 每罐指定一台“库存计算仪表”，其他仪表仅供对比监测；体积和质量每罐只计一次。
3. 顶部区分储罐数与仪表数，库存合计注明计入罐数和数据不足罐数。
4. 指定仪表数据无效时，库存记为数据不足，不当作零、不用过期值，也不自动改用其他仪表；人工切换需权限并留痕。
5. 罐型、尺寸、罐容表等由物理罐共用；通讯、位号、操作按仪表配置。工况密度来源仍按已确认规则选择，20℃标准密度保持独立用途。
6. 若以后采用该模型，建议将卡片隐藏与是否计入库存分开；此项也是候选设计，本次不改变现有隐藏与统计行为。

## 影响

仅更新项目记忆。未修改源代码、数据库、运行后台、配置、安装程序或客户交付包。总览压缩顶部、侧栏收起、八列卡片等画面方案仍属于独立讨论，不受此暂缓决定自动批准或取消。
