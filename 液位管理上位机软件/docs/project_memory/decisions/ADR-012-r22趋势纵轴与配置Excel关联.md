# ADR-012：r22趋势纵轴、配置Excel关联与复制

## 状态

已确认、已实现，2026-11-07。用户明确要求在当前r22修改、检查并重新启动，不另起版本号。

## 背景

用户确认此前讨论的各项纵轴、浅灰边框及独立罐组关联页方案，并要求趋势选择当前罐、加曲线沿用该罐、复制尽可能保留原配置。

## 决策

- 九类趋势量各自支持自动最小跨度和固定上下限，按罐持久保存；数值按内部标准单位保存，页面按所选显示单位换算。相同数据项跨罐比较共用刻度，不同数据项独立坐标。仅改变坐标，不改样本或平滑数据；超出固定范围明确提示数量和真实极值。
- 新设置默认液位100mm、温度5℃、密度20kg/m³、体积公称容量1%（最少1m³）、质量按公称容量和人工密度（无则800）的1%（最少1t）、压力10kPa。默认值可改；不替换旧罐已保存设置。单罐详情的实时三曲线使用同罐保存的设置。
- 趋势页“当前储罐”载入该罐预设；增加曲线默认当前罐及未重复数据项。跨罐临时比较仍保留，保存共用设置要求曲线属于当前单罐。
- 配置导出升级TANK-CONFIG-3：档案主表不再放多值罐组字段，增加“罐组关联”页，每行一个罐号、一个罐组，可多行关联同罐。出现的罐按整组替换；罐号加空组明确清空，未列出的罐保留旧关联。重复组合、空组与其他组混用、未知组均拒绝。导入需预览后确认；兼容格式1/2原分号字段及英文枚举。
- 所有Excel导出通路及提供的三种罐容模板应用浅灰细边框FFD9E1E6，不改变模板公式、数据和验证。独立关联页使用普通下拉，不引入宏。
- 复制保留启用、隐藏、置顶、分组、罐容三表、计量、报警、操作、温度和趋势参数，以及选填档案；只生成新内部ID、清空罐号和通讯地址、名称标注副本。必须填新罐号及通讯地址后主动保存，不直接下发动作。取代旧版“复制默认停用并清除部分关联”的实现。
- schema保持17；r22本机更新使用新运行快照，原13罐、配置revision5、原数据/profile/授权和两条通道完整保留。COM2是用户已配置通道，不能再把此现用会话描述为全loopback。升级器只恢复原采集运行状态，没有提交仪表控制。

## 影响

当前r22仍是中文联调候选，未封装新版安装包，也未新增六小时长测。r20/r21密封包、旧运行快照、备份与全部验证记录保留，两版后台继续停止。

用户本轮明确指令；415项单元、10组纵轴纯逻辑、20组界面/下载、12组复制与三表往返、10个实际Excel/1234单元格边框核验，见output/r22-phase2-20261107。运行切换证据output/client-viewing/r22-update-1794037030533。
