# ADR-011：工况密度与五列小数罐容表

## 状态

已确认；r21已实现并通过隔离回归，现场检定资料与实机待验收。

## 背景

客户20261103反馈要求人工工况密度与实测密度并存、小数罐容表按检定区段累计增量计算。用户接受五列模板，并确认不足1mm使用线性插值，明确保留r20版本。

## 决策

- 工况计算密度由用户按罐选择仪表实测或人工工况密度，静压力修正和质量使用同一所选来源。缺值不自动替代；20℃标准密度独立保存，不代替工况密度。实测值隐藏仅影响显示。
- 小数表固定五列：起始高度mm、结束高度mm、序号1～9、厘米累计增量L、毫米累计增量L。每区段9行，起止重复，累计值直接抄原表，不以单毫米值乘序号替代。
- 基础体积算法按罐互斥选择主表插值或主表下节点加小数表。组合算法使用实际下节点（如440mm），精确主表节点直接采用主表；447.5mm在447/448mm计算结果之间线性插值，不外推。
- 区段须连续、不重叠，边界与主表节点一致。旧两列小数表保留查看，不能直接用于五列组合算法。旧罐不自动切换算法。
- 系统导出的Excel“资料”页明确记录表类型、单位、静压力参考密度，重新导入采用该元数据且保持数值；元数据无效则拒绝，不静默回到默认单位。外部文件缺少元数据时由用户核对选择单位，不按数值量级推断。
- 配置格式2兼容旧格式1和旧字段名。旧模板缺少新增计量字段时保留已有配置。可空项与0区分，必填缺失明确报错。导入先预览、确认后保存。
- schema由16升级17，使旧版拒绝降级打开，避免旧程序忽略新算法和密度字段产生误算。升级前保留业务备份，回退r20用升级前备份；新版恢复工具同步兼容17。
- r20完整ZIP、数据、授权和源基线保留；所有r21测试使用独立数据、随机本机端口，无现场仪表写入。

## 影响

罐容计算、质量、历史计量依据、配置导入导出、显示和打印同步采用新字段。新增默认只影响新配置，不覆盖现用r20。隔离功能回归不等于新六小时长测或计量认证。
