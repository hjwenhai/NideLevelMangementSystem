# ADR 016 r22 图形安装向导

## 状态

已确认。2026-11-10 用户要求制作常规 Windows 图形安装程序，支持安装内容、程序目录、数据目录和快捷方式选择。

## 决策

- 用 Inno Setup 6.4.3 的宽松许可版本构建中文离线单 EXE。构建工具下载签名已验证，工具仅在项目 .build-tools 内；6.7.4 未授权商业编译模式不用于客户交付。
- 本机完整安装包含后台、客户端、维护恢复和文档；仅客户端可填写远程服务根地址。新安装目录可选，升级按服务和 installation.json 识别并沿用原程序、数据目录及端口。
- 使用标准 Windows 安装、卸载记录和开始菜单，桌面快捷方式可选。WebView2 使用旧完整包已校验的离线安装程序。
- 前端及业务二进制继续使用 20261107-r22-u2，不修改现用数据和授权。新发布入口独立于原密封 ZIP。
- 安装引擎正常停止旧服务。文件安装失败回退服务设置；若新后台已尝试启动，保留业务库并停机核查，避免原程序误开升级后的库。
- 卸载清除程序管理的文件及服务，保留业务数据及旁边的授权保护目录。旧脚本安装的历史版本目录不递归删除。
- 暂无供方代码签名证书，EXE 为 NotSigned。向客户明确首次授权窗口可能出现未知发布者。供方业务授权私钥不用于 Windows 代码签名。

## 验证

安装引擎 19 项、实际 QA 安装包 29 项检查通过。包含完整安装、原路径升级、仅客户端、取消准备后恢复、卸载保留数据，以及代表性 schema16 数据库升级到17，原账号登录、配置、历史和事件一致。此旧库为隔离兼容样本，未以真实客户库或原 r18 二进制重新验收。

实际编译脚本使用 SetupQa 预处理配置，替换 AppId、服务和快捷方式名称，正常服务不受测试影响。PreviewOnly 只用于画面核对，禁止实际安装，不发给客户。

证据位于 output/wizard-installer-qa_20261110；发布入口及最终 SHA 见 release-summary.json。未新增长跑，未接入真实仪表。
