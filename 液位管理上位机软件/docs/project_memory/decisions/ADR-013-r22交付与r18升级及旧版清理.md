# ADR-013：r22客户交付与r18直接升级及旧版清理

## 状态

已按用户要求执行，2026-11-07。

## 决策与结果

- r22完整客户包采用build 20261107-r22-u1、schema17，包含完整自包含程序、WebView2离线运行环境、新版维护与恢复工具、4页Word升级指南、6页Word操作说明、对应HTML、三类罐容模板及只读接口说明。平均温度资源保留，按原有效授权及设备条件使用。不包含客户数据、预设客户账号、签发工具或私钥。供方内部品牌设置不在客户说明中介绍。
- 客户r18可以直接升级r22，无需中间版本。先业务备份、退出旧客户端、停止后台服务，再沿用原目录/8780运行安装.cmd。新版本目录由安装程序生成，标准公共桌面快捷方式随之更新，installation.json记录VersionRoot。额外手建旧快捷方式须核对。通常不要求重启电脑。
- 用实际r18隔离样本验证账号密码、通讯、分组、ATS高度0、主表、0水体积、历史与授权保留。升级由schema16到17；旧计量维持Instrument及Interpolate默认，不自动启用新算法。旧r18会拒绝打开已升级库。
- 正常恢复到r22使用本包新版桌面恢复工具。若回退到r18，应由技术人员用原r18维护工具恢复升级前r18备份并切回旧程序。新版恢复工具会初始化并升级旧备份为17，不能用它制作r18回退数据。实际隔离回退验证通过，恢复核查生效且不自动采集。
- 包含1202清单文件加清单，ZIP CRC与每文件SHA通过；最终仅发“_发.zip”。发布后不得原位改文件或覆盖密封ZIP；后续另存新产物。完整目录名本身不带“_发”，最终ZIP内部是安装.cmd等根项。
- 用户要求“除了r20与当前版其余清理删除”，已删除非r20/r22的旧管理系统交付包、运行副本、构建和旧样本库。原容量测试库约15GB也已清除。源码、客户原始资料、协议、私钥、供方工具及全部r20/r22根目录保护。通用outputs下的模板制作源资料仍作为必要源文件保留。
- 旧验证记录不作为旧程序保留：3173文件按原相对路径压缩留存到cleanup-records/20261107-keep-r20-r22/旧版验证记录与源码快照.zip并逐文件SHA校验，约197MiB。另归档旧模板制作资料后仅移除工作区链接，没有删除外部依赖目标。
- r20保护前后2463文件SHA全部一致，私钥仅检查大小与时间元数据且不变；运行中的r22 Host28356未启停，清理后全机仅该管理系统Host，现用13罐/COM2和数据继续保留。旧版验证路径后续从归档按原相对路径查阅，不能据历史session.json的Running认定仍有后台。
