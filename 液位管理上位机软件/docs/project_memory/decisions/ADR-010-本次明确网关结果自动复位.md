# ADR-010：本次明确网关结果自动复位

## 状态

已确认/已实施，2026-11-02，r20。用户认为每次人工复位和填写记录繁琐，确认按建议自动处理，并要求数据过期时间默认30秒。此项调整ADR-009的正常结果人工收尾规则；未知、外部遗留和身份/周期变化保护继续保留。

## 决策

- 普通动作、独立停止和远程液位修改的本次网关终态3/4，在原结果持久化后创建独立IsAutomaticReset日志并自动写所选结果通道0，再查询空闲。失败原因仍保留为Rejected，不因为自动复位而改成成功。
- 只有提交前通道空闲、本次指令值一致、累计计数精确增加1、身份/绑定/会话匹配、计数未饱和，才建立GatewayResultSnapshot自动收尾依据。明确06拒绝、未发送失败、未知5、其他工具遗留结果无自动接管。
- 自动复位记录RelatedControlId指向已明确结束的原操作，GatewayResetExpectation冻结原结果；存储层验证原结果、操作者、目标、通道及状态一致，不可覆改标记或依据。自动收尾按原动作权限复核，不要求操作者另外具备ControlReview；手工复位仍要该权限和确认。
- 原操作保留active直到收尾结束，普通新动作等待；独立停止仍能优先处理正常动作，不取消已经明确结束的收尾。复位应答丢失单独记未知，不重试，不改写原动作结论；重启不自动续跑动作或收尾。手工核查入口保留。
- Domain原有新配置默认30秒保持；此前演示脚本为了测试设3秒，未来新版演示统一30。现有现场值不自动覆盖，UI说明默认30。管理系统过期时间不覆盖网关原有效位/分组时效及故障判断。

用户询问如何让客户电脑无网关、无仪表演示。已说明必须配套本机模拟器，新增通道本身不产生数据。建议独立一键演示包，单独数据/授权/端口，清晰标记模拟；或单独模拟网关EXE加手工127.0.0.1/固定端口/Unit1配置。

当前仅交付讨论稿deployment/docs/客户电脑模拟展示方案_讨论稿.html；客户一键演示工具和模拟网关桌面EXE尚未实现或交付。内部Node脚本依赖开发环境及供方测试授权，不能直接发客户。tools/Start-R20Preview.cjs已准备为内部开发用，未启动，不能冒充客户工具。
