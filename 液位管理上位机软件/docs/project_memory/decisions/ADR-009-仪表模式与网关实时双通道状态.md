# ADR-009：仪表模式与网关实时双通道状态

## 状态

已确认，2026-11-02。用户要求停止按钮普通样式、显示当前仪表模式、网关双通道实时状态及复位提示、下发前检查，并更新测试版。r19实施；不改变ADR-008取消远程位门槛的决定。

## 背景与依据

现场1号网关仪表：main指令/状态/错误为0，独立stop指令1、状态3、错误0。上位机只检查正常通道，提交测量Ⅰ收到06；原IR51状态4被正确视为停止，实际位置不当液面。处理旧停止结果、恢复测量Ⅰ后IR51=32769、液位恢复。用户无法从旧操作日志判断网关当前是否空闲，固定红色停止按钮又易被误解为状态。

依据网关docs/12_客户通讯协议V3.md第8节：普通动作需正常和独立停止均空闲；独立停止可在正常忙时请求。终态3/4/5锁存需复位，1/2不能复位，5须先核查；复位不停止或重发。单控制方及无迟到旧写重试规则仍有效。

## 决策

- 停止普通白底带图标，当前模式独立文字；直连/网关按原仪表位字、L25按自己的枚举，状态无效显示未知。按钮颜色不作为运行状态。
- 网关当前详情约4秒只读刷新FC03控制12字；跟随原采集连接，不新开物理串口。身份/绑定复核、配置与采集会话检查；读取失败或前端10秒未更新显示未知，不能作为空闲依据。直连/L25不显示网关面板。
- 新普通动作及液位参数修改下发前检查两通道；执行准备后再检查；停止只要求自己的通道可用。明确06拒绝不标为机械动作未知；丢回执/无法确认仍未知且不自动重发。
- 复位入口集中到实时通道，只有3/4/5显示，需ControlReview、现场结论、勾选确认。复位保存原通道值/状态/错误/累计计数及设备身份；刷新、服务受理和准备写入阶段复核选定周期，变化则拒绝。64位boot ID以字符串传前端，避免JS精度丢失。状态5无自动复位。
- 复位只写所选原寄存器0，不停浮子、不恢复模式、不重放动作，不自动改写旧未知操作的核查结论。旧记录复位按钮移除，人工核查记录保留。
- 桌面读取health.revision并按版本查询参数导航；HTML禁用直接复用旧首页，安装完成检查revision后缀。程序分版本目录安装、原数据及授权路径保持。

## 验证与限制

378项单元、17组新增接口/界面、25组既有网关动作、12组控制/重启、10组原生包/桌面/恢复/安装预检通过。1920×1080/100%完整操作布局一屏、无横向溢出。证据output/r19-gateway-live-qa_20261102。

只写隔离本机模拟器；没有实际网关/串口控制，没有替换或停止现用后台。r19没有另跑6小时，r18六小时不能作为r19结果。目标Windows服务升级与真实机械工况待验收。IR26 −310℃是否为仪表异常仍待资料/现场状态，不在此次擅改有效性规则。

北向协议没有跨控制方原子比较并复位接口；累计计数/状态复核防止旧确认误用，但不能替代现场单控制方约定。复位前结束其他工具的控制写入和重试。
