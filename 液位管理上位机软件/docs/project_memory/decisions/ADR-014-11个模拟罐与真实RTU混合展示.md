# ADR-014：11个模拟罐与1台真实RTU液位计展示

## 状态

已按用户明天现场使用需求完成配套模拟器，2026-11-07。原r22完整升级包不重封、不改现用配置；本工具单独交付。

## 需求与接入

客户升级前r18只有一台真实液位计，现场RS-485 Modbus RTU地址1。增加11个虚拟罐，经GT6757X Modbus TCP本机通道进入同一r22画面。两条通道的地址1独立，不冲突。

## 实现

- 新增tools/LevelManager.GatewaySimulator.Core（纯BCL协议模型与回环TCP服务）及WinForms GatewaySimulator；自包含win-x64，客户不需要Node、Python、开发SDK、虚拟串口或单独.NET。
- 默认11槽位、127.0.0.1:15020、Unit ID1。可选1～64槽位和端口，但只能回环监听，没有串口或出站连接代码，不接触数据库、客户配置、授权和供方密钥。启动前不监听，端口占用明确失败，不接管或关闭其他进程。
- 按当前r22点表提供液位/位置、IR26、密度、16点ATS、模拟4～20mA输入、组质量、序号、启动标识、普通动作/独立停止结果和远程液位暂存。模式及结果可由r22读回、自动收尾。只模拟简单位置变化和明确终态，不代表机械到位；没有完整V1.3无线浮子平均测温状态机。
- 演示工具Header19保持r22接入所需的正常帧兼容格式；用户必须用SIM-01～SIM-11、“模拟展示”组和模拟名称明确标识来源，不能把这些值作为现场库存。IR时间未确认标记保留，不冒充现场仪表时钟。
- 值只存在内存，重启清初始模拟值、启动标识变化；不会清管理系统历史。慢变化限制0～12000mm，空/满罐也不溢出。支持模拟离线/故障及恢复正常。
- 附模拟主罐容表SIM-CT-3000（0～12000mm、0～3000m³线性展示表），由实际r22导出；不能关联真实罐。用户先新建SIM-01并绑定模拟通道、示例表和ATS，再复制10个并改罐号/槽位，不能从真实罐直接改绑复制。
- 模拟值会进入历史和总览合计，按真实罐分组筛选实际库存；演示结束只停用SIM罐/模拟通道及工具，不能停止总采集后台影响真实仪表。

## 验证

424项单元通过（其中9项模拟器：正式读取器11槽位、ATS/压力、双结果通道、远程暂存、故障/离线、边界、分帧/粘包、端口释放、混合地址配置验证）。真实串口仅验证配置绑定规则，未实际打开。

原生模拟器接密封r22正式后台6组集成通过，1号/11号各类动作及自动复位、远程液位、总览11卡/详情、模拟主表导出均通过，43次写入均为回环模拟。移除DOTNET环境和开发PATH后独立运行及协议收发通过；原生窗口启动记录11行、15020且默认停止。CUA窗口目视检查因app approval timeout未取得截图，不把该项写为已完成视觉QA；程序化原生启动检查与管理系统画面检查已通过。

证据output/r22-simulator-qa_20261107：simulator-final-unit.trx、integration-latest.json、native-final.json、native-window.json、package.json。最终版V1.0.1；早期V1仅内部候选，已退役，不发客户。
