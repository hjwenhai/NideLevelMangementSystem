# ADR-020：r23 客户反馈与人工水位计算

## 状态

已确认并实施，2026-11-13。依据客户《系统问题反馈_20261111.docx》（正文日期2026-11-12）、用户同意的八列总览图及本轮人工水位答复。另存 r23，现用 r22 的程序、数据及运行入口不替换。

## 决策及实施

1. 当前继续一罐一表，沿用 ADR-019；不实施反馈中的多仪表/重复罐号。新增先填写唯一仪表位号和罐号；顶部跨页签显示两项，页签按仪表档案、通讯绑定、罐容表、计量参数、操作与温度、报警配置排序。兼容旧档案空位号及历史恢复身份；新建或变更位号检查唯一。
2. 测量Ⅰ、停止、上升、重复性检查、液体震荡回避为基本操作选项，仍受逐罐配置、权限、协议与期限约束。测量Ⅱ、测量Ⅲ、下降、远程密度、远程液位修改分别以供方签名模块开通；未开通不显示，后台直接请求也拒绝。新导出模板不显示未授权选配列，旧配置保留、不自动删除。供方签发桌面工具已补五项选择。
3. 总览分组/介质在四张降低高度的汇总卡之前；顶部筛选、汇总、状态固定，卡片区域滚动；左栏可收起为图标；紧凑罐图保留100×155px，1920×1080、100%缩放、收起左栏时八列。置顶用图标，密度同行、净体积/质量同行；未配置均温时不显示该项但保持卡片等高。库存口径不变。
4. 单罐位号优先显示并加大字号。已知非测量Ⅰ模式时，灰显本采集会话最近有效液位与冻结时间，仅作展示；不能用来恢复有效液位质量、计算库存或把浮子位置当液位。通讯过期/未知/无旧值时保持缺测。罐图显示已配置液位报警限标记及提示。
5. 用户确认水位为手工水层高度mm。按当前所选基础罐容算法计算水体积，再从整体修正后体积扣除；不对水体积重复应用整体静压力修正。水位0表示无水，留空兼容旧人工水体积；高于液位或超表范围时报无效、不外推。Excel和历史计量依据记录相应设置。
6. 历史和事件查询、操作与表头保留，表体独立滚动；历史保持手工查询。
7. 罐容表增加删除确认；任何当前储罐关联均阻止删除。删除采用schema18墓碑，当前列表移除，历史版本及历史计算依据保留，防止旧缓存重新出现。
8. 所有面向用户的IFX协议名称统一IFX30000，内部枚举IfxL25不变。公开表地址=(站号−1)×32…站号×32−1，转换为原内部序号1…32。站号与串口参数可编辑，仍校验支持范围；不再固定38400/偶校验/站号1。
9. 配置Excel为TANK-CONFIG-4，增加水位并输出IFX表地址；导入1/2/3版本仍按原内部罐号处理。r23表不能导回r22。

## 兼容与交付

- 数据库schema18；r23可升级旧数据。回退r22须停新后台并使用升级前备份，不能把r22直接连升级后的库。
- 原授权继续用于基本操作及原平均测温；五项选配操作须用新工具重新签发对应模块。客户先升级r23，再导入新授权，旧r22不识别新模块。
- 安装包：`output/客户安装向导_r23_20261113/液位管理系统_r23_安装程序_20261113.exe`；同行HTML说明及release.json。
- 供方工具：`output/供方授权工具_r23_20261113.zip`，不含私钥与客户授权，不交终端客户。私钥原位置未修改。
- 现用r22入口及运行目录保持；源码修改前快照：`output/r23-feedback_20261113/r22-source-before.zip`。
