# ADR-004：到期授权与最后阶段英文支持

## 状态

交付顺序补记：后续用户已明确P7先交付中文客户测试版、P8下版开发英文和未确定项；按ADR-005与V1.2计划执行。本记录的到期规则继续有效，下文V1.1交付安排为历史。

已确认需求，2026-10-27用户明确要求参考温度浮子项目到期停机功能，并支持英文、英文最后开发。本轮完成规则梳理和计划更新，尚未实现授权模块或英文版，未设置具体客户到期日期。

## 背景

ADR-001及V1.0方案曾明确不默认带入旧授权。用户现在明确新增此功能，原决定相应更新。已阅读参考项目ADR-057、P9、授权维护说明和src/Application/TestAuthorization.cs；参考项目到期时并不退出实时监控。

## 决策

沿用离线签名、安装绑定、供方签发/客户管理员导入、延期/永久、7/3/1天提醒、精确到期、时钟保护和业务恢复不续期规则。到期限制新计划/任务、常规控制、历史查询及导出；保留实时采集/监控/报警确认/归档、停止和必要恢复、当前回执及核查，已有执行上下文完成原流程。失联/重启/续期不自动重放动作。具体能力矩阵见V1.1整体方案第10节。

与旧项目相同，首次未授权即相关能力受限；不能只隐藏菜单，后台也检查。新系统独立产品标识/密钥，禁止沿用旧客户授权和具体日期。只在供方工具签发，客户不能自行修改期限；不新增付款检测、云授权或远程关停接口。

P1预留策略及消息标识，P4/P5随功能接入检查与当前任务例外，P6完整实现授权，P7做中文综合验证。英文功能最后在P8开发、回归并完成双语最终交付；前面先用稳定枚举/错误码/事件码和参数，为资源化预留边界。中英文切换仅改变显示，不改变单位、协议、数据、权限或期限。

## 影响

V1.1总体方案和阶段清单为现行开发入口，V1.0保留历史。新增P8；P7调整为中文验证与发布准备，避免将中文候选包误写为双语最终交付。当前V0.1.0工程功能、原型、原协议及客户Word均不改；到期授权和英文不可标为已完成。

参考项目的具体日期、客户授权、签名私钥、旧数据库和完整Framework DLL不复制。后台实时与处置能力不应受历史门禁误伤；ATS实时平均和最新无线任务结果继续按监控显示。到期不删除数据；正常历史保留策略仍有效，续期只能查询仍保留的数据。
