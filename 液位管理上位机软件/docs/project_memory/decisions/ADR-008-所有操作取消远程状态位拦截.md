# ADR-008：所有操作取消仪表远程状态位拦截

## 状态

已确认，2026-10-30。用户明确要求“取消仪表远程状态位拦截。检查其他动作都要取消远程状态位拦截”。r18实施，取代ADR-007对自动测温、恢复、IFX和参数修改保留远程位判断的边界。

## 决策

所有已支持的仪表操作与流程都不再以远程状态位为前置拦截条件，包括手工普通动作、测量Ⅰ恢复、IFX普通动作、直连远程液位参数修改、自动平均测温的启动/移动/停留/恢复。网关既有模式独立策略保持。

远程状态字继续按原值读取；IsRemote仅保留为状态解释函数，产品代码不再调用它作控制判断。新鲜有效数据、真实故障、权限、授权、按罐白名单、认证、握手、模式与位置/停稳/容差回读、未知不重发等保持；温度缺测0x8000及故障位规则不变。未开放协议不支持的动作或未经确认的能力。

## 原因与影响

r17手工测量Ⅰ在服务入口从其他模式返回时会标记IsRecovery，进入仍保留的检查分支，所以出现“上升成功、停止成功、测量Ⅰ被拒绝”。本次去掉所有操作分支内的远程位检查，保留“已在测量Ⅰ则无需重复恢复”的实际模式判断。前版遗漏已写入回归。

356项测试通过，原实现12个有针对性的用例失败，包括测量Ⅰ恢复、IFX、直连参数修改和完整平均测温。全源码审计无CommandEncoding.IsRemote调用，仅状态解释定义保留。只进行软件/模拟验证，不代替真实仪表验收。
