# ADR-005：中文测试版优先与下一版范围

## 状态

已确认，2026-10-27用户明确“先跟客户交个中文测试版，未确定的项与英文在下版开发”。本轮更新交付规划，不代表测试版已完成或已发给客户。

## 背景

V1.1将P7定位为中文候选包准备，P8双语回归后才最终交付。最新要求明确中文测试版先独立交付，应避免英文或尚未确定需求阻塞客户试用。

## 决策

P0～P6完成首版已确认业务及到期授权，P7完成适用容量、可靠性、安装与设备验证后交付中文客户测试版；P8为下一版，处理首版反馈、英文及已经得到确认的延后项。首版发布号在实际打包时确定，当前V0.1.0基础工程不是该客户测试版。

首版保留已确认采集/配置/监控/计量/历史/报警/操作/测温/管理和到期授权；128罐、60秒、一年SQLite基线不变。必要网关适配、权限及收尾不能因技术复杂而直接归为“未确定项”。

英文、VCF、小数表组合算法、三类暂未启用报表、未开放参数写入/新增操作与外部接口尚未约定部分进入下一版需求池，资料确认后开发。首版保留约定入口/维护能力，未启用项不参与计算、不返回虚构成功或结果。本机页面所需API及已经明确的外部接口不一并暂停。

交付中文运行包、版本/功能/未启用与已知问题清单、安装使用/备份恢复/授权说明、验证结果和反馈表。未实测设备条件明确记录，不将模拟结果视为真机通过。下一版升级保留配置、历史、产品安装标识及授权，不清库、不因升级延期或自动重发动作。

## 影响

V1.2整体方案和阶段清单成为现行入口；V1.0/V1.1保留历史。ADR-004的到期规则继续有效，其交付顺序由本记录更新。英文继续作为后续语言工作，不是中文首版条件。

本轮仅修改文档与项目记忆，未变更代码、客户Word或原型，未打包或发送客户测试版。后续继续完成基础存储样机，再推进已确认中文业务。
