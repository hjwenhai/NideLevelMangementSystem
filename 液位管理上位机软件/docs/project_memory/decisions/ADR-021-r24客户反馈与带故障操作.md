## 决策

1. 总览复用单罐详情的冻结显示条件：当前采集会话/配置和通讯有效、有最近正常液位、有效浮子位置、当前模式已知且非测量Ⅰ。标签为液位冻结，数字和罐图灰显；只改变展示，不恢复液位有效性，不进入体积、质量、库存计算。离线、停采、过期及状态未知不借用旧值显示。
2. 储罐配置位号、罐号分列，位号在前。网关TCP及RTU编辑项改为网关槽位号，并加用户指定鼠标提示；数据字段和Excel格式不变。
3. IFX五个故障定义按红字改为温度计超量程/7、模拟量输入超量程/9、参数错误/A、电机错误/1、浮子控制错误/8。映射改按协议故障编码匹配，不再依赖中文描述；其他项及FW对应表不擅自补码。故障首次时间沿用，不重写旧控制记录。同步修正IFX监测分类：0x0010/0x0020不再按旧英语名称认作内部错误而整组清空。
4. 普通手工操作的前置检查和下发后的确认不再要求故障字为零。仍要求新鲜通讯和实际状态、逐罐开放、许可、用户权限、配置/绑定身份、每次认证及本次回读；故障字未知与通讯错误不同于已读到非零故障，不能放行。
5. 参数修改从设备重新读取原始位置并核算偏移；仅控制内部读取可绕过按故障码对测量值的展示屏蔽，不改变普通采集和计量的质量。原始高度无效仍禁止偏移计算。自动测温不再仅因故障码非零中止，但实际位置、鲜度、模式、到位及温度有效性约束保留。
6. 状态3仍只代表指令回读确认，不能解释成机械到位。明确拒绝记失败，应答或模式不明记待核查，不自动重发。旧网关仍可能返回历史错误3，平台不替换实际结果；需要网关0.8.3或兼容后续版本才能端到端带故障操作。

## 边界

本次未实施前次仅讨论的测量Ⅰ返回液面过渡状态、平衡区解锁或L25人工液面确认方案。也未实施一罐多仪表、罐容小数表外推或改变报警/库存有效性规则。
