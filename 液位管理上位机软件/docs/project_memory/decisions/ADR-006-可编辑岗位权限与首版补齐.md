# ADR-006：可编辑岗位权限与首版补齐

## 状态

已确认：2026-10-28需求方要求优先完成原讨论第2、4、5、8、10、12项，随后持续开发；下一版中文测试包使用6小时测试。以下实现细节为本次工程选择。

## 背景

原程序以管理员、操作员、浏览员固定分配权限，原型存在细粒度矩阵；配置Excel、ATS图点位、页面刷新及历史质量筛选需要补齐。已有供方模块授权、到期策略、逐罐允许操作及设备写入证据不能被新增配置绕过。

## 决策

1. 保留三个既有岗位，增加17个功能权限。普通功能逐项配置；账号管理、岗位管理、供方授权与业务恢复核查由管理员保留，避免失去恢复管理入口。开放仪表控制或平均测温必须保留停止。
2. 权限存入业务SQLite独立表，schema14→15迁移不改历史表。矩阵带版本号，变更与审计同事务，冲突拒绝；备份包含矩阵。Cookie每次请求加载当前权限，后台服务首次写入前再查当前账号及权限。已首次下发的任务保留必要安全收尾。
3. 每次矩阵变更使旧定时测温授权版本失效，即使后来重新勾选功能，也须重新编辑确认该定时任务；不自动重放或补跑。
4. 配置Excel只处理储罐档案、绑定、报警、计量及温度/允许操作。通道、介质、罐组及罐容表为已有引用；三个配置页对应罐号。新增/更新而不删除未列出罐。拒绝公式、宏、外部链接、超限和错误引用。上传只预览；10分钟、绑定账号、一次性令牌确认保存，保存时再次验证配置版本及当前权限。允许操作仅配置，不发送动作。
5. ATS图只定位已知且在罐高内的高度，0mm有效；其他点在列表中显示。正常点平均规则不改变。
6. 页面刷新1～30秒是显示参数，不改变设备轮询和历史周期，不重开采集。过期判定继续推进，不冻结旧值为有效。
7. 历史质量按选中的9类数据项分别过滤，直接在SQL中筛选；分页及流式Excel使用同一条件，正常0与无效空值不混用。

## 影响

升级前保留业务备份；schema15业务库不能由旧r9程序降级读取。供方授权与独立写入保护目录仍不随业务恢复回滚。英文、三类报表、VCF/小数表未定规则、第二优先画面不混入本轮。
