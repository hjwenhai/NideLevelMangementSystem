## 已核实的计算顺序（第7项）

基础体积＝主表插值，或主表下节点加小数表增量（二者互斥）。
实际静压力修正＝修正表按液位查得的增量×所选工况密度÷表参考密度。
修正后当前体积＝基础体积＋实际静压力修正。
净体积＝修正后当前体积－人工水体积。
质量t＝净体积m³×所选工况密度kg/m³÷1000。
无修正表时修正量为0；20℃标准密度不代替工况密度。
依据：src/LevelManager.Domain/Metering.cs MeteringCalculator.Calculate，本轮未改算法。
