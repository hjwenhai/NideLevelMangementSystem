## 小数罐容表推荐计算方案

保留主罐容表、小数表、静压力容积修正表三类，但每罐明确选用一个基础容积算法：

- 主表插值：适合已提供逐厘米/逐毫米完整容量点，按原确认规则插值，不再叠加小数表。
- 主表查下节点加小数增量：适合分米主表与厘米毫米分区增量配套的证书。选不大于当前液位的最近主表节点H0，不能硬编码取整分米，因存在440、1060、1709、1757mm等非整分米节点。H-H0拆成整厘米、剩余整毫米及不足1mm部分；厘米和毫米分别用该适用区段对应的累计值，一次相加。整节点时余量为零；区段上界使用对应主表精确节点，避免重叠。所有区段边界应能与主表节点核对。
- 原表提供区段容量系数时，应按证书确认的区段系数计算或导入已经由客户检定机构认可的细化主表，不强行转换成某一套厘米毫米增量。

厘米/毫米表中的数值是累计增量，例如2mm=454L、7mm=1588L并非简单227L/mm乘出来。保留原精度，不先对系数取整。厘米列和毫米列的0项取0，完整性/重复/区段重叠与缺口都要校验。

原61-T-710示例：
- 4.40dm=440mm，主表440mm为99165L。
- 当前447mm，H0=440mm，余7mm，该区段7mm累计增量1588L，基础容积=100753L=100.753m³。
- 若误把H0取成400mm，主表90095L加4cm9074L及7mm1588L=100757L，多4L。
- 527mm：500mm主表112776L，加2cm4537L和7mm1588L，得到118901L。只按500～600mm主表线性插值是118900.95L，两种算法因原表取整可能有微小差异，不能重复叠加。

随后再用完整当前液位查静压力修正量并乘实际工况密度/参考密度（已确认默认1000kg/m³），扣人工水体积，再乘所选工况质量密度计算质量。静压力是否已包含、温度/浮顶等额外修正，以该罐正式证书和已确认范围为准，不能因本次模板调整而声称全部计量因素已实现。

待客户确认：447mm等普通点、非整分米节点前后、区段边界和缺表点样例；0.1mm是否在相邻毫米累计值间插值或按指定规则处理；何时取整及误差容许值。原表1mm步长下，小于1mm的插值属于拟定规则，不当作已确认。
