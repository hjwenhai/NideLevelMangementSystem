## 提取事实

参考项目按安装编号签发，客户不能编辑截止日。授权与clock状态不放业务数据库，恢复业务库不延长时间；首次未授权即限制指定能力。7/3/1天提示，签发时刻/到期时刻用UTC，界面按当地时区显示；可延期或永久。

到期限制新测温/计划、常规控制、历史查询、导出/打印和手动备份；监控、报警及确认、采集归档、停止及必要恢复继续，已开始任务及已写入命令完成原流程/握手。排队未写入常规命令再次校验；导出发布前复核。后台不会因期限到达直接退出。中断或重启不自动恢复运动。

参考实现时钟回拨超过5分钟进入时钟异常，小幅回拨使用进程单调时间和已观察时间保护；观察到过期立即保存时间状态，避免过期后回拨重新激活。签名或状态异常进入受限，保留监控和处置。维护说明没有保证客户电脑管理员无法修改程序或使用旧版本。
