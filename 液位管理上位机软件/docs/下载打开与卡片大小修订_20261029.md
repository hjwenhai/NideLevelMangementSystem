# 下载打开与卡片大小修订

本轮针对用户反馈：下载文件名虽正确，但打开文件、打开文件夹无响应；总览缺少卡片大小入口。

## 实现

- 原生客户端接管下载完成记录，提供下载列表、打开文件、打开文件夹。页面右上角“下载文件”可再次打开列表；Ctrl+J/默认下载窗口入口同样转到本列表。
- 点击打开文件时，用 Windows 默认程序打开已完成下载的文档；打开文件夹时交由资源管理器定位该文件。文件被移走、删除或系统无法打开时给出提示。下载不会自动打开文件。
- 记录位于该客户端 profile/download-records.json，最多保存100条供下次重开；不删除下载文件。
- 网页消息只接受可信后台页面发出的固定“打开下载列表”请求，不接受网页指定文件路径、命令或打开动作；文件打开必须在原生列表中由用户选择。本轮保留原有同源导航限制和禁用宿主对象。
- 仅接收本后台 HTTP/HTTPS、同源 blob 工作簿和 PNG 图片下载。可直接打开的类型限 XLSX/CSV/ZIP/JSON/PNG/PDF/TXT，不能借此运行 EXE、CMD、LNK 等文件。
- 总览图形模式的筛选区增加“卡片大小”：紧凑、标准、大号，默认标准。实际改变图形、卡片高度和列数。本机浏览器/profile独立记忆；列表模式隐藏此控件，回到图形模式保留选择。共享置顶、隐藏、统计范围不变。
- 重开预览脚本补上本项目已有的 .NET 运行时定位，只对该脚本子进程生效。
