# P1基础工程实施与验证

日期2026-10-27；工程V0.1.0。P0方案及任务已整理，P1第一批基础功能已实施。此记录只报告实际执行结果，不代替正式业务或现场验收。

## 已实现

C#分层解决方案及Vue前端；首次管理员、密码登录、基础角色策略、Cookie与CSRF、登录限流；采集通道和储罐配置、最多128罐后端校验、不同协议参数/站号/内部编号校验；SQLite初始化迁移、配置不可变版本、并发冲突拒绝、变更与审计同事务；事件六分类、条件查询及当前结果导出；真实SQLite状态显示。无默认账号密码。

数值质量/时效/采集会话/配置版本模型及Modbus只读帧、CRC、带符号和倍率解码已建。尚没有真实串口/TCP传输、后台采集、控制或平均测温。保存连接信息只入库，设备端口不会被打开。

当前SQLite迁移版本1。配置、账号和事件已保存；历史设置仅保存参数，尚未生成历史表、到期清理或长期曲线。配置备份使用真实SQLite备份API并在测试中重新打开验证；用户完整备份/恢复入口和全年历史恢复在后续阶段实现。

- 项目内微软.NET SDK10.0.403，运行时/ASP.NETCore10.0.14；SDK的官方SHA512已比对，验证文件在.build-tools/sdk-verification.json。
- EFCore/Microsoft.Data.Sqlite10.0.14、SQLitePCLRaw.bundle_e_sqlite3 3.0.5。运行时sqlite_version()实际返回3.53.4，不能只看NuGet包名称判断原生版本。
- Vue3.5.22、TypeScript5.9.3、Vite7.2.2；pnpm11.25.0，前后端依赖均有锁文件。
- 前端生产资源离线打包；正式工程的测试数据、运行数据与原型及上个项目分开。旧Go探索稿在archive中保留文件散列，未作为正式软件使用。

## 文件与运行

内部工程入口为“启动工程版.cmd”，使用本机http://127.0.0.1:8780，首次建立管理员。停止用“停止工程版.cmd”。当前需要本开发机项目内.NET工具和PowerShell7，最终自包含离线安装包在P7提供。

主要产物为src、web、tests、tools及本轮docs；数据和缓存不随源代码分发。相关截图在output/p1-verification，机器可读检查结果及工程程序集散列在output/p1-verification/verification-manifest.json。受限开发沙箱曾阻止测试宿主回环/命名管道，最终检查是在允许本机进程通信的环境完成；失败的环境尝试未记为通过。
