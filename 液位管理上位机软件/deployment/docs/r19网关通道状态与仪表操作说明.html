r19 网关通道状态与仪表操作说明

2026年11月2日 · 中文测试版 · 后台标识 20261102-r19

一、仪表模式与操作按钮分开显示

“停止”改为普通白底按钮，带停止图标，不再固定红色。操作区显示“当前模式：测量Ⅰ / 上升 / 下降 / 停止……”；无有效状态时显示未知。按钮用于下发指令，按钮颜色不代表仪表当前模式。直连RS-485、IFX L25和GT6757X均按各自协议解释状态。

二、网关两条通道实时显示

网关接入的储罐，在操作区显示“正常动作”和“独立停止”的实时状态，当前页面约每4秒读取一次，也可点“刷新”。读取不成功、配置待保存或状态过期时显示“状态未知”，不把旧记录当作空闲依据。直连及L25储罐不显示网关通道。

状态处理方法
空闲无需复位；新动作下发前后台仍会再次检查。
已受理 / 执行中继续查询，不允许复位。
回读已确认 / 明确失败或取消保留本周期结果；现场核对后，点该通道旁的“复位结果”。
结果未知先核查浮子运动、位置、仪表模式及原动作，再点“核查并复位”。不能直接重试原动作。

复位需要核查结论、明确勾选和确认。提交前重新读取并核对设备绑定和周期；若画面打开后已进入新周期，会拒绝旧确认，要求重新核查。结果通道复位成功以实时空闲状态和回读记录为准。

复位只清除所选通道的结果，不停止浮子、不恢复测量Ⅰ、不修改液位、不重发动作，另一通道不受影响。两通道均空闲也不表示浮子机械停止。新动作需要另行明确下发。

三、下发前检查

新的普通动作及远程液位修改要求两条网关通道均空闲。若独立停止结果未复位，直接提示“独立停止结果待复位”，不会先提交再仅显示异常码06。独立停止仍可在正常动作忙或结果未知时单独请求，但自身停止通道必须可用。状态不可信时不发送新动作，不自动复位或重发。

四、操作记录与人工核查

直连、L25及网关都保留“操作记录与回读”。历史结果未知时可以填写“人工核查记录”；它仅保存核查结论，不写入网关。网关复位入口集中在实时通道旁，不再在每条旧记录下重复显示，避免误选历史记录。实时结果复位不会自动改写旧未知记录；旧记录的核查仍需按实际情况填写。只保留一个控制方，复位前结束其他工具或网关网页的控制写请求。

五、从r12/r18升级

  1. 先创建并保存业务备份，核对原安装目录、业务数据目录和端口。
  2. 处理现场未完成作业，关闭客户端，停止Windows服务“液位管理系统后台”；若手动运行后台，则退出对应后台进程。软件退出不等于浮子机械停止。
  3. 完整解压本包，在原安装参数下运行“安装.cmd”。不需要卸载旧版，不删除原数据或授权保护目录，schema16不变；安装程序不强行停止现用后台。
  4. 安装完成后打开标准桌面“液位管理系统”快捷方式，登录后左侧应显示r19。自行复制或改名的旧快捷方式需改指向本次安装客户端。最新路径可从默认安装目录的installation.json中查看VersionRoot。
  5. 浏览器默认打开 http://127.0.0.1:8780/api/health，revision应为 20261102-r19。自定义端口按实际值。桌面客户端会按后台revision加载页面，避免升级后继续使用旧版首页。
  6. 原配置、账号、历史和授权沿用。升级后核对通讯及两条控制通道；既有只读采集自启策略保留，不会自动复位结果或重发原动作。
