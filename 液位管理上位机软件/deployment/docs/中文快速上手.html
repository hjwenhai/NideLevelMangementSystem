1. 安装与首次登录

  1. 完整解压安装包到本机磁盘，勿在压缩包内直接运行。
  2. 运行“安装.cmd”，在Windows提示时允许管理员权限。默认只监听本机127.0.0.1:8780，不自动开放防火墙或局域网。
  3. 安装程序核验包内文件；如缺少WebView2，使用随包微软完整离线安装程序。客户电脑无需安装Node、Python、SDK或单独.NET开发环境。
  4. 从桌面打开“液位管理系统”，先建立管理员，再登录。没有出厂通用密码。
  5. 系统管理→软件授权：保存本机安装请求，交供方签发授权，再由管理员导入。截止时刻由双方约定；本包没有自动试用天数。按本机安装请求导入授权后生效。

r9新增档案资料与品牌显示

罐体档案新增名称、产品编号、设备批次、罐径、公称容量及所属罐组配置入口，操作与温度页可填写备注。新增资料均为选填，罐径和公称容量不代替罐容表计算；纯档案修改不重启采集。侧栏显示供方配置的厂家名称、标识及副标题，软件名称用于窗口和登录。通讯绑定可先选择协议，再明确绑定匹配通道。详细原型差异见随包逐项对照清单，待补功能未计作完成。

本版界面入口

储罐配置分为“罐体档案、通讯绑定、报警配置、计量参数、罐容表、操作与温度”六个页签；切换保留输入。先应用到待保存配置，再保存配置统一生效。输入有误时会自动转到对应页签。

管理员可在罐区总览、罐清单列表或单罐详情设置置顶，所有用户共用排列，筛选仍然生效。“基础数据”集中提供罐容表、介质与计量、显示单位、定时任务；“系统管理”分为基本参数、账号与权限、数据库维护、对外接口、软件授权。停止采集位于基本参数，顶部“采集管理”可直达。

2. 配置后启动只读采集

  1. 通讯通道：直连RS-485 Modbus RTU、IFX L25，或GT6757X Modbus TCP/RTU。填写实际电脑串口或网关IP、站号、通讯参数。
  2. 储罐配置：新增罐号，选择通道和协议对应地址/内部罐号；可设置介质、罐型、报警、计量、温度及允许操作。仪表位号可留空，系统最多128罐。
  3. IFX3W011单个COM口、一个站号可读全部32罐；COM1/COM2不是两个16罐站号。IFX主机侧使用RS-232C；直连仪表使用RS-485。网关南向每COM最多16通道、全机最多64槽，北向Unit ID与内部槽号分开。
  4. 温度选项为不带温度计、ATS或无线浮子；ATS与无线浮子互斥。IR26为瞬时温度。ATS已设置点数中，正常读到的所有点参加实时平均，包括0℃和液面以上的正常点。
  5. 保存配置后点击“启动采集”。新安装默认不自行打开通讯，也不发送仪表动作。可在系统管理勾选“服务启动后自动开始只读采集”，保存后从下次服务启动生效；数据恢复待核查时不会自动开启。

关闭桌面窗口不停止后台服务。Windows服务重启不续跑仪表动作或测温任务；原未决结果需要人工核查。停止采集不等于机械停止，实际仪表的停止应使用相应操作并核对现场。

3. 画面与数据

入口用途
罐区总览、罐清单、单罐详情液位、位置、瞬时温度、ATS或最近成功任务均值、完成时间、密度、体积、质量、压力、状态及报警。离线/过期值显示“—”，不假装新数据。罐清单支持按当前显示单位导出Excel和打印；历史可打印当前查询页。
罐组、介质、显示单位共用分组、上下级、介质颜色及单位。隐藏只影响画面和汇总，仍采集报警归档；停用则停止该罐采集和归档。
报警中心活动、待确认和历史报警。确认仅表示已知悉；无效读数不会把原报警当作恢复。阈值、回差、持续延时按逐罐配置。
历史、趋势、事件记录默认60秒保存、保留12个月。历史沿用当时值和计算版本；趋势缺测断线。操作日志、报警和通讯/任务错误统一在事件分类查询。
快照、定时任务、后台数据任务快照固定一时刻结果；定时快照按设置执行，不补跑错过时段。已开通并具备直连条件时，可设置定时平均测温；管理员须明确授权自动操作，密码、岗位或启用状态变化后需重新确认。后台“申请完成”不表示实际测温完成。Excel和数据库备份在后台生成，可查看进度、取消及下载。
仪表操作只显示逐罐已允许操作，需适当岗位与明确确认。写入或模式回读成功不代表机械到位。结果未知时不自动重发，需核查。
三类报表单罐作业、罐区产品汇总、动态即时报表保留入口，标注“暂未启用”。

仪表故障按适用协议说明显示，同一故障持续存在时保留首次检测时间；多条故障按首次检测先后排序，同一批次按协议位顺序排列。该时间是本软件首次检测时间，不冒充仪表实际发生时间。离线时不把旧故障列表当作当前故障。

4. 计量规则

主罐容表按液位查表插值。静压力修正按“表中修正量×实际仪表密度÷参考密度”，参考密度默认1000kg/m³，可随修正表修改。修正后当前体积扣除人工水体积得到净体积，质量=净体积×仪表密度÷1000（吨）。人工20℃标准密度独立保存，不代替实测密度。

缺少密度、表或有效液位时不填零、不外推。小数表可管理和关联，其与主表的正式组合规则及标准体积VCF未确认，当前不参与计算。罐容表支持批量关联和取消本表关联。

5. 平均测温的当前边界

直连流程已按V1.3编码和流程模拟验证：起始稳定、基准停留、冻结液面、逐点下降/停止/停稳/停留、读取I6、N/M判断、恢复测量Ⅰ后公布均值；每点正常停留10分钟，不能以回执代替停稳。仍需实际仪表验证停距、状态与异常处理。网关固件当前缺整任务一次认证及停留后新读I6的北向接口，IFX缓存更新关系未证明，这两种平均测温入口保持限制；它们的瞬时温度采集不受此项限制。

6. 到期后

历史查询、导出、手动备份、新测温和普通新动作受限；采集、归档、实时监控、报警确认、当前回执、必要停止和恢复/核查继续。到期不会一键停止所有罐，也不会删除业务数据。续期应导入供方签名文件；恢复旧业务数据或修改电脑时间不能延长授权。

7. 保存期限与备份

缩短期限会自动清理超过新期限的历史。请先按当前已保存配置创建业务备份，随后在系统管理选择该备份并确认，再保存新期限。备份须24小时内、配置版本一致，系统重新核验SHA256。详细恢复步骤见《备份恢复与维护》。

r10新增功能

入口操作与规则
系统管理→账号与权限在岗位权限矩阵中勾选管理员、操作员、浏览员可使用的功能并保存。当前登录账号的后续请求按新权限校验。账号、岗位、供方授权及恢复核查由管理员保留。允许仪表操作或平均测温时须同时保留停止权限；不改变本罐开放操作及设备限制。
储罐配置→导出／导入先导出配置或下载模板。填写三个配置页，保持表头和对应罐号；通道、介质、罐组、罐容表编号从参考页复制。上传后预览，逐罐检查字段原值和导入值，再勾选确认保存。未列出的储罐保留；不会自动发送仪表动作。预览10分钟内有效，有其他用户保存配置后须重新预览。仅支持本系统xlsx模板，不导入账号、授权或定时任务。
单罐详情→ATS已填高度的测点按实际高度标注点号；未填高度或超出罐高的点在列表显示。0mm不是空值；所有正常读取点仍参与平均，不按液面剔除。
基础数据→显示单位页面刷新间隔1～30秒，与通道采集周期和历史保存间隔分别配置。修改刷新间隔不重启采集，过期数据仍按时间失效。
历史数据先选“状态对应数据项”，再选正常、全部无效或具体状态。液位正常不能代表温度正常。分页及导出沿用已成功查询的条件，0与无效空值分别保留。

岗位权限矩阵修改后，原定时测温授权须重新编辑并确认；不自动恢复旧授权。正在执行的任务仍保留必要停止和收尾。
