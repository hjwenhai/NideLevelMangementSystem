对外只读接口 V1

首个联调接口采用HTTP REST，只提供当前数据。最终外部点表及DCS组态需双方确认；不开放控制写入、参数修改、历史数据库或账号管理。其他接口协议待确认后另行实现。

开通

管理员在系统管理→对外接口，选择允许读取的罐，勾选确认并生成独立令牌。仅本次显示明文；后续只能重新生成，旧令牌随即失效。新增罐不自动开放，关闭接口会吊销令牌。令牌不能代替软件账号登录。

GET /api/external/v1/current
Authorization: Bearer <独立只读令牌>

默认只有本机可访问。其他主机需明确配置监听、网络及HTTPS，安装程序不会默认开放局域网。返回JSON，Cache-Control: no-store；最多120次/分钟，建议2秒一次。无效/未启用返回401，配置切换冲突可重读，超限返回429。

主要字段

字段含义
schemaVersion / generatedAtUtc / configurationRevision接口版本1.0、软件生成时间UTC、当前配置版本。
tanks[].id / code / enabled / hidden内部ID、罐号、是否启用及是否画面隐藏。仅返回管理员所选范围。
points.level / floatPosition液面高度与浮子实际位置P，单位mm，不能混作同一值。
points.instantTemperature / averageTemperatureIR26瞬时温度，以及ATS实时平均或上次成功任务均值；℃。
density / currentVolume / netVolume / masskg/m³、m³、m³、t；当前体积含静压力修正，净体积扣人工水量。
pressure1 / pressure2 / atsPoints两路压力kPa及逐点ATS温度/质量。
每点value / unit / quality / qualityCode / isCurrent / source / sampledAtUtc数值、单位、质量及代码、是否当前有效、来源、原时间。无效值为空，禁止转换为0。
receivedAtUtc / sourceTimeConfirmed / sourceAtUtc软件收到时间、来源时钟是否确认及来源时间。未确认来源时间时采用软件接收时间，不能当作仪表时钟。
averageTaskId / averageCompletedAtUtc最近成功任务标识及完成时间，旧均值不充当当前新测量。
alarms.active / unacknowledged / recoveredUnacknowledged活动、未确认、恢复待确认的数量。报警汇总和采集分别读取，非同一硬件采样事务。

质量码

代码/名称含义
0 Good正常当前值，isCurrent=true。
1 Missing无可用读数。
2 Offline离线或采集停止。
3 Expired数据超过软件期限或接收时钟异常。
4 Fault设备或数据故障。
5 Unconfigured未配置/停用。
6 Held本次平均测温冻结液面及相关体积；保留原冻结时间，isCurrent=false。
7 Historical上次任务平均温度；保留原完成时间和任务ID，isCurrent=false。

接口中的冻结/历史值可保留数字用于解释当前状态，但接入方必须同时判断质量与isCurrent，不能持续报“当前有效”。授权到期仍保留此实时只读监控能力；恢复业务后接口保护配置失效时应重新生成令牌。
