客户电脑模拟展示方案（讨论稿）

2026年11月2日。目的是不连接真实网关、液位计，在客户自己的电脑上演示软件画面和常用操作。

这是实施建议，客户演示模拟器/一键演示包尚未随r20交付。现有开发用模拟脚本依赖开发环境，不适合直接发给客户；仅新增“独立模拟网关”通道不会产生数据。

一、需要两个程序配合

模拟网关程序在本机产生虚拟液位、IR26温度、密度、ATS数据和状态，按当前GT6757X点表响应Modbus TCP。管理系统作为客户端连接它，并按真实流程显示、保存历史和查询操作结果。模拟器不打开串口，不连接任何现场仪表。

二、建议做成独立的一键演示包

给客户一个可直接运行的Windows程序，提供“启动演示”“停止演示”按钮，自动准备专用演示目录、样例储罐及罐容表，启动本机模拟器和演示后台，再打开客户端。不要求客户安装Node.js、Python或输入命令。画面明确注明“模拟展示数据”。正式运行数据及授权保护目录保持独立，停止演示不影响正式后台。

演示环境需有相应演示授权，不复制生产授权保护目录，也不把供方私钥或签发工具交付客户。可预设样例账号、三种罐型、不同温度配置及正常/报警/掉线场景。演示范围应标明哪些只是模拟响应，不能作为真机测量或机械停稳验收。

三、若先做单独模拟网关工具，手动连接方式如下

  1. 先运行配套模拟器，点击启动，确认显示“正在监听127.0.0.1:15020”（端口示例，以实际显示为准）。
  2. 在专用演示管理系统新增通道，按下表设置；不要在正式生产配置中混入模拟来源。
  3. 新增样例储罐，绑定该通道，内部编号与模拟器槽位一致，例如1、2、3。启用后启动只读采集。
  4. 查看液位、温度、ATS、趋势、报警和操作流程；浮子操作只改变模拟数据。关闭模拟器后管理系统会显示通信异常，不会自动切到真实设备。
配置项示例
通道名称独立模拟网关（本机）
协议GT6757X Modbus TCP
地址127.0.0.1
端口15020，必须与模拟器显示一致
Unit ID1，与模拟器一致
储罐内部编号1～模拟器已提供的槽位数
管理系统数据过期时间30秒

127.0.0.1表示本电脑。若模拟器在其他电脑，该地址就不适用；本方案优先只在一台电脑内演示。模拟器必须实现当前网关点表、数据质量、两条控制通道、周期和复位规则，普通只有几个随机寄存器的Modbus工具不能完整代替。
