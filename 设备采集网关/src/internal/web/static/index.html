    网络设置
    

    分别设置网口1（eth0）和网口2（eth1）的固定IPv4地址。两个网口使用不同子网，默认网关只在一个网口填写；不需要跨网段通讯时可都留空。
    

    修改将短暂中断采集、网页和Modbus通讯。请先结束并核查、复位已有控制结果。试用开始后180秒内，通过新地址重新登录并确认；未确认、试用期间断电或重启，会恢复修改前设置。确认后断电保留。

    忘记IP或改错后如何恢复
    先断开其他网关并用电脑直连本台。厂家sysrst服务正常时，系统启动后长按FUN约3秒，蜂鸣提示后网口1临时恢复192.168.1.230，网口2临时恢复192.168.0.230。电脑设置同子网地址，使用原网页端口登录；管理员密码不变。进入本页检查或重新修改，重启后仍使用已保存的配置。仅在设备原厂FUN恢复功能已核验时使用。
    若FUN无效，使用Console UART查看或修复网络，按说明书“网络设置与失联恢复”操作。恢复IP不会清除密码、仪表绑定、历史或控制记录，也不会停止浮子。
    

    修改管理员密码
    只修改网页登录密码，不影响液位计采集。成功后所有已登录会话退出，请用新密码重新登录。
    

    新密码为12～128个ASCII字符，无首尾空格，不能与原密码相同。请妥善保存；忘记密码由厂家在设备终端恢复。
    

    网页升级
    选择厂家提供的.gwup文件，上传校验后再确认安装。升级保留配置、管理员账号、历史数据和控制记录。
    

    请安排维护窗口并先结束、核查和复位原控制结果。安装期间采集与Modbus通讯将中断，请勿断电。升级网关程序不等于停止浮子。
