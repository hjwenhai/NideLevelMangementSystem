# ADR-023 TCP网口唯一修改入口与端口分离

日期：2026-11-09。状态：实施于0.8.1。

用户确认“系统维护”选择接入网口，“端口与仪表”仅修改服务端口并显示可复制地址。原两个入口均能改写tcp.listen，容易混淆或覆盖。

普通配置Apply在任何串口或TCP停启前检查监听host必须与当前一致，只允许端口及其他原服务参数变化。网络事务仍从所选网口计算host，保留服务端口，按原180秒人工确认／恢复流程应用。初始配置、厂家离线维护及现有schema3组合地址存储保留，不新增北向寄存器或数据库字段。

网页改为TCP服务端口输入及只读地址卡，状态接口提供当前已保存TCP配置。双口方式列出两网口地址，不复制0.0.0.0；地址未知明确提示。导入配置保留本机host，只导入原文件端口；后台直接请求改host仍拒绝，不靠隐藏输入限制。

未保存端口不改变只读运行地址；没有本地草稿时配置版本变更自动重读，有草稿时由原配置版本检查拒绝旧草稿覆盖新网络参数。永久授权、现场控制状态和北向V3.2-D2保持。
