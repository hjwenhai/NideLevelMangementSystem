# ADR-015：网页密码修改与程序重启

2026-10-19，用户批准实施。软件0.3.7，D2点表/schema2不变。

网页增加系统维护，修改密码需原密码、新密码及确认，12～128个ASCII字符。登录、会话及凭据更新以读写锁串行，避免修改后仍受理旧会话或旧密码登录；凭据原子替换后当前校验立即更新，注销所有网页会话。准备事件无法登记则不修改，文件已提交但同步或完成审计异常时按新密码生效提示警告。采集核心不重启，明文密码及hash不进入事件。

程序重启通过主程序的独立worker调用启动时指定的固定service.sh restart-web，不接受HTTP脚本或命令参数；Linux使用独立session，避免停止原监督器时一并停止任务。service.sh正常停网页、停核心，再启核心/网页，安装锁存在时拒绝。执行失败而旧核心仍存活则解除重启门控并留错误，不自动重试。

重启与配置/北向提交共用applyMu，检查正常及独立停止没有状态1/2后置pending，原核心存活期间拒绝新控制/复位、改配置及校时。状态3/4/5保留，重启不复位、不补发，也不证明浮子停止。重复请求返回同一任务ID。前端提示中断、确认现场、等待重连并要求重新登录，超时由人员检查。

默认HTTP、WATCHDOG空值继续保持；整机重启不实现。新运行包仍13文件，复用现有核心二进制和服务脚本，无新后台可执行文件/系统依赖。普通电脑演示和未经适配的systemd启动不提供网页程序重启。板端行为与软件模拟分别记录。操作及控制开通见[26](../docs/26_系统维护与控制写入操作说明.md)。
