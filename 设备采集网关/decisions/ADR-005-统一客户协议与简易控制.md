# ADR-005 统一客户协议与简易控制

## 状态

部分由[ADR-006](ADR-006-三寄存器控制与独立停止.md)替代：正常触发/两字提交改为D2单字指令提交，以下保留D1历史。统一客户协议、读取及独立停止原则仍有效。

原状态：已确认，2026-10-10。用户认可简易寄存器控制，并要求先修改文档、全面梳理检查；本轮授权范围是文档，不修改运行程序。

部分替代ADR-004：客户读取与控制不再另册，客户不处理64字邮箱。厂家配置职责、稳定编号及保留已有测量地址继续有效。

## 背景

客户把网关作为Modbus TCP Server，期望写少量对应寄存器即可控制仪表。V2对外邮箱要求启动/绑定/来源/序号及64字提交，集成负担较大。参考IFX指令—触发—查询流程，复杂机制应由网关承担。

## 决策

- 一份[客户通讯协议V3设计稿](../docs/12_客户通讯协议V3.md)同时包含读数及简易控制；只读客户不必实现控制章节。厂家配置和诊断仍使用内部文档。
- 保留V2测量地址/编码，新控制采用保持寄存器30000～30383，每编号12字，FC03读、FC06或FC10写；独立停止入口避免正常命令忙时不能停止。地址及状态为设计基线，代码未实现。
- 客户不填写内部命令ID/来源邮箱/boot_id/binding；网关内部冻结绑定、生成ID、持久化和去重。正常/停止各有锁存，重复1不重复下发；终态3/4可清0，状态5须厂家核查。触发复位不是取消或机械动作。
- 新接口标北向V3，客户文档V3.0-D1；当前运行软件0.2.0/V2/schema2不变。新保留字28/29用于能力/步长声明，旧客户读取可保持数据地址，控制必须版本/能力检查。
- V3对北向关闭旧64字邮箱写入口，内部可以复用命令引擎；不能同时开放绕过锁存的客户入口。本轮不修改现有V2入口。
- 同一仪表单一控制方、串行请求；只承诺同一锁存周期不重复执行，不承诺清零后迟到请求可无条件识别。独立停止是软件控制，不是硬接线急停。

## 影响

需求V0.6，V3设计资料成为下一阶段实现依据；旧V2文档/资料包留历史，厂家点表09仍反映当前已实现V2。内部设计14、V3点表15、任务/验收/部署/告警说明必须同步。现有代码、生产配置、机器点表及已发布压缩包不改。

普通参数写入、任意位置、真正任务完成语义仍需另行设计或厂家确认。现有导出脚本和发布脚本未改，未来必须升级版本识别和交付流程；不能把V3设计包当0.2.0可执行协议。
