# GT6757X网络升级实施范围

2026-10-29，软件0.6.0。用户已选择网页直接上传升级文件，不采用U盘。

当前实现管理网页上传厂家签名的.gwup文件，校验型号、架构、版本及完整性后由管理员确认安装。独立执行器负责停服、一致性备份、原子切换、启动验证和兼容原应用恢复。配置、账号、历史及控制记录保留；不恢复旧数据库，不自动复位或重发动作。

首版适用于项目service.sh管理的Buildroot部署。先由厂家手动安装基础版，后续客户在网页完成升级。原完整手动安装、升级和维护命令继续保留。详见[网页升级操作说明29](29_网页上传升级操作说明.md)、[部署说明10](10_运行部署与维护.md)和[ADR-020](../decisions/ADR-020-厂家签名网页应用升级与持久化互锁.md)。

北向V3.2-D2、配置及数据库schema3、64槽位保持。升级协议1只接受兼容应用包；不含Linux内核、系统镜像、网口IP修改、自动公网推送或整机重启。网页升级期间存在采集与通讯中断，不承诺零停机。systemd接管、跨schema迁移及系统A/B升级未纳入本次实现。

软件验证与板端验收分别记录。现有本机测试不能代替实际Buildroot启动、掉电恢复、双网口与四口采集测试。旧网络升级评估已归档至archive/web-upgrade-20261029，不能再作为“网页尚未开发”的现行说明。
