# 寄存器与写入方案 V3.1-D2（实施版）

2026-10-19容量修订：每南向COM最多16台，整机64槽位；四南64台仅TCP，三南一北最多48台，两南最多32台。原1～32号绑定不搬移，升级自动扩展槽位并迁移schema3。详见[容量与升级说明27](27_十六台每口扩容与升级说明.md)。

软件0.3.1按D2实现。规范：[客户12](12_客户通讯协议V3.md)、[厂家15](15_北向寄存器点表V3.md)、[状态机14](14_简易控制内部设计与状态机.md)。运行JSON为protocols/north-v3.json；V2文件仅历史。

## 读取

扩展至64稳定编号，原1～32号保持、24字摘要、144字详情、48字只读参数及原倍率/质量/有效位/分组时间。64台主要值15000、15100、15200、15300各96字；多响应不保证同步。完整摘要1536字分13次（12×120+96）；每请求最多125字且不跨区域。严格值/有效性对应时读单台摘要。客户同一Unit ID，地址区分仪表。

## 控制

C=30000+12×(n-1)。FC06写C+0合法非零指令即提交，FC03读C+1起2字，C+0写0复位0/3/4；5经人工核查后可复位，1/2拒绝。C+7写1独立停止，C+8/+9查结果；停止0复位规则相同，5须人工核查；两个通道独立。FC10仅这两个单字形状。C+3保留0，诊断计数保留，不作为去重ID。40000邮箱所有读写关闭。

客户动作枚举转成HR699单动作位，取得新鲜IR51/52、HR129认证、HR699只写一次、HR698和IR51/52回读。状态3仅指令接受确认，非机械完成。普通参数写、直接改缓存触发、D1两字提交均不支持。

## 持久化与停止

每台正常/停止各自锁存，事务同时保存内部ID、冻结目标、计数及审计；同周期相同重复不加计数、不再发。发送前持久化声明，掉应答回读不重试控制。重启1/2变5/9，3/4/5保留；未知经人工核查后向原寄存器写0复位，禁止自动复位或重发；上位机记录人员/结果，网关记录来源、时间、原控制和复位后状态。停止在每帧结束后优先，取消尚未声明发送正常项为4/11；不能消除旧未知。每台单一控制方，跨周期迟到限制见12。

## 厂家配置与版本

配置schema3，数据库schema3新增control_slots，V2未决/未知导入锁存不重放。入口许可、允许动作、硬件写开关分别控制。任一非空闲周期时拒绝有变更配置。客户协议不包含配置写寄存器；管理员网页处理配置和核查。板端测试尚待完成，见08/10/16。

软件0.8.3允许仪表有故障码时下发已开通的操作和独立停止，仪表自身判断是否执行。网关根据通讯应答及指令回读确认控制结果，故障字、质量告警和SYS3告警按实际情况继续显示。旧状态4／错误3保留，可经人工核查后复位，再提交新动作。
