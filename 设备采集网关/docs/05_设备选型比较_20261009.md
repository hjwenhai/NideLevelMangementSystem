# 已选设备与容量复核

本文保留当时选型/协议评估记录，旧容量不作为现行约束；现行每口16台、整机64台见[27](27_十六台每口扩容与升级说明.md)，当前客户接口见[12](12_客户通讯协议V3.md)。

2026-10-10，已选GT6757S（512MB/8GB）。当时完整选型、报价和比较资料已保存[历史比较](../archive/v1/docs/05_设备选型比较_20261009.md)，历史容量假设不再有效。

## 当前选型结果

GT6757S双核A35、800MHz、512MB内存、8GB eMMC、两路100M以太网及四路独立隔离485，允许部署本项目编译程序。COM3/4的232与485复用，总UART仍4路。规格事实来自本地资料/source_notes，订货配置与固件须实机核对。

## 本次容量变化

每南向最多8台；两路16台、三路24台、四路32台。保留一口北向RTU最多24台；32台只能TCP北向。CPU/内存余量不是把四个口变成第五口的依据；维护网口不消耗485口。每口8台减小线传预算，默认快速目标3秒，实际性能仍待板测。

## SYS指示灯

已确认SYS1/2/3可编程，分别用于运行、采集和告警。节点/dev/led、led2、led3来自Buildroot手册；本版驱动已实现、三灯点亮尚未测。灯规范见11，当前需求01。
