# GT6757X远程液位修改与验收说明

软件0.5.0　协议V3.2-D2　2026-10-29

本功能把现场核实的目标液位换算成仪表偏移量，并写入液位计。仪表负责保存该参数。网关不会只改显示值，也不会在通讯失败后自动再次修改。首次使用须在试验仪表上验收。

## 1 依据与换算

依据项目原件《通讯协议/FW9000NN远程液位修改.docx》，适用于直连RS485及经本网关。这里的寄存器号为十进制零基报文地址。该方法不使用IFX控制字，也不向FW的HR699发送液位修改命令。

| 项目 | 南向操作 | 中文说明 |
| --- | --- | --- |
| 当前液位RLevel | FC04读IR0、IR1 | 有符号32位，高字在前，原始整数÷10为mm；执行时重新读取，不使用网页或3秒缓存。 |
| 原偏移ROffset | FC03读HR503、HR504 | 有符号32位，高字在前，原始整数÷10为mm。 |
| 液位修改认证 | FC06写HR129=0xEA66 | 与浮子动作的0x10D9不同；每次液位修改重新认证。 |
| 新偏移WOffset | FC10写HR503、HR504 | 两字一次写入；WOffset=WLevel−RLevel+ROffset。 |
| 回读确认 | FC03读HR503、HR504 | 必须与本次计算值一致；只回读，不自动补写。 |
| 结束认证 | FC06写HR129=0 | 认证尝试后，无论写入成功、应答丢失或停止取消，都尽力清零；断电时不能保证完成。 |

文件给定偏移设置范围−9999.9～99999.9mm。软件对目标液位和计算后的偏移均限制在该范围，精度0.1mm；这是目标输入的保守限制。计算采用64位整数，防止32位加减溢出。

例：当前液位15000.0mm，原偏移−500.0mm，目标15010.0mm，则新偏移−490.0mm。原始整数为−4900，二进制补码高/低字为0xFFFF、0xECDC。修改后显示会继续随真实液位变化；不能要求运动中的浮子在回读时恰好等于目标。

## 2 网页操作

1. 登录管理员网页，进入“端口与仪表”。核对槽位、名称、COM口与仪表地址，勾选“远程液位修改（校准）”，保存并应用。
2. 实机须按[控制写入操作说明](26_系统维护与控制写入操作说明.md)开通HARDWARE_WRITES=1；升级不会自动开通。Modbus入口还须分别开通TCP或北向RTU的写许可。网页登录后提交不依赖Modbus TCP连接或其写许可。
3. 进入“历史与诊断”，展开“远程液位修改”。选择液位计（切换后会清空旧目标并立即切换状态），输入目标液位（mm，最多1位小数）、操作人员及核查原因。
4. 确认现场液位、仪表和目标值，勾选现场确认，点击“确认修改仪表液位”。普通动作和独立停止应均空闲；否则先处理其结果。不要在浮子移动或其他主站同时修改参数时校准。
5. 等待结果。状态3才表示HR503/504回读一致，且HR129清零应答已确认。状态4为失败或取消，状态5须核查实际偏移及认证状态。查看“命令结果”中的level_adjustment可核对原液位、原偏移、新偏移和认证清零标志。
6. 核对结果后重新勾选确认，点击“复位本次结果（不重写）”。它只清除本次控制记录，不恢复原偏移，不重写液位，不停止浮子。再做一次校准须重新输入并确认；禁止自动复位或自动重试。

## 3 上位机操作

读取数据的原点表不变，北向版本寄存器地址2仍为3；新增地址30=1表示软件具有远程液位修改扩展，不代表现场已许可。目标液位为有符号32位0.1mm整数，高字在前。

对仪表n，目标区J=31000+4×(n−1)，正常控制区C=30000+12×(n−1)。全部地址为零基十进制。仪表1的J=31000、C=30000；仪表64的J=31252、C=30756。

| 字段 | 地址 | 读写 | 中文说明 |
| --- | --- | --- | --- |
| 目标液位高字、低字 | J、J+1 | FC03读；FC10连续写2字 | 必须整对写；FC06、半字、跨槽位或夹带其他字段一律拒绝，不会部分生效。只准备目标，不修改仪表。 |
| 目标已准备 | J+2 | FC03只读 | 1表示本次目标与当前配置/绑定匹配，可提交；0须重新写两字目标。受理后清零，重启后清零；读到0的目标值不能直接提交。 |
| 保留 | J+3 | FC03只读 | 当前为0，客户忽略。 |
| 提交或复位 | C+0 | FC06写 | 11提交远程液位修改；0只复位允许的终态，不改仪表。 |
| 状态 | C+1 | FC03只读 | 沿用0空闲、1已受理、2执行中、3回读确认、4失败/取消、5不确定。 |
| 错误码 | C+2 | FC03只读 | 沿用原错误码，新增12偏移越界、13回读不一致、14认证清零未确认。 |

先确认C+1=0且C+8=0，再用FC10写目标两字；可读J+2核对准备成功，然后FC06写C+0=11，轮询C+1、C+2。重复11仅返回原受理结果，不重写；状态1/2禁止复位。状态5须客户人工核查并留档后写C+0=0复位。Modbus不携带人员和原因，客户上位机负责确认提示与留档，网关记录连接来源、时间及原控制记录。

目标区只有暂存值，没有参数修改功能；普通浮子指令仍不需要目标区。每台仅指定一个控制方，避免多个客户端覆盖待提交目标。配置或绑定变化后，旧目标不能提交。配置默认不含512权限标记，512只用于网关许可，绝不写入南向HR699。

仪表1目标15010.0mm=150100=0x00024A54：先FC10写31000起2字[0x0002,0x4A54]，再FC06写30000=11，FC03读30001起2字查询。认证及偏移计算由网关完成，客户不用直接处理HR129或HR503。

## 4 失败处理和恢复

| 情况 | 结果 | 处理 |
| --- | --- | --- |
| 当前液位/原偏移读取失败，或仪表不支持HR503/504 | 状态4、错误10；未写偏移 | 核对仪表型号、固件、线路和地址；人工处理后复位。 |
| 新偏移越界 | 状态4、错误12；不认证、不写偏移 | 核对目标、原液位及原偏移，不截断或钳位数值。 |
| 认证应答丢失 | 未写偏移；仍尝试清零HR129 | 清零确认后状态4/4；清零未确认则状态5/14。 |
| 写应答丢失但偏移回读一致，且认证清零确认 | 状态3 | 不补写；保存回读与计算依据。 |
| 偏移应答/回读无法确认 | 状态5，错误6或13 | 人工读取仪表偏移量、核对实际液位，禁止自动重写。 |
| HR129清零无法确认 | 状态5、错误14 | 核查偏移量及认证状态；网页/Modbus的结果复位不会替仪表清认证。 |
| 独立停止插入 | 偏移发送前取消；认证尝试后仍清零 | 已经可能发送的偏移不撤销；停止结果单独保留，核查两个通道。 |
| 任务期间断电/程序中断 | 恢复为状态5、错误9；不重放 | 实机认证清零可能未完成，先核查HR129及HR503/504。 |

网关在偏移写入前持久化原液位、原偏移、新偏移和发送占位。审计失败时停止写入并锁存。修改后立即尝试重新采集液位；若失败，将旧液位标为无效，等待新采集。状态3只证明参数回读及清认证应答，不证明现场液位正确、断电保存成功或计量精度。

## 5 上板验收

在试验液位计确认HR503/504可读写、FC06认证有效、字序与倍率符合资料。先记录原偏移及液位，做小幅修正，核对目标换算、实际偏移、网页与北向新读数；再由现场人员确认是否恢复原偏移。不要由测试脚本自动修改真实设备。

抓包应包含FC04读IR0/1、FC03读HR503/504、FC06写HR129=EA66、FC10写HR503/504、FC03回读、FC06写HR129=0；不出现液位修改对应的HR699写入。断开通信验证不自动重写；重启验证未决结果5/9、不自动恢复认证或偏移写入。断电后核对仪表自身参数保存，这是板端待验收项目。

升级沿用[运行部署与维护](10_运行部署与维护.md)，新包为0.5.0-20261029-r2，NORTH_VERSION文件标记3.2。数据库schema3及gateway-v2.db文件名不变；新程序能读取旧浮子控制记录。出现命令11记录后，旧程序不具备恢复能力，因此本版安装器和回退脚本禁止自动回退至标记3.1及更早版本，不恢复旧数据库。
