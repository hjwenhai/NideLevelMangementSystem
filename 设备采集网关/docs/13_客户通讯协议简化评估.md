# 客户通讯协议简化评估与确认记录

2026-10-11，厂家内部。最新决策为[ADR-006](../decisions/ADR-006-三寄存器控制与独立停止.md)：客户使用一份协议，读取沿用V2，控制用指令/状态/错误三寄存器。原“另交64字邮箱控制专册”已被替代，历史原稿归档archive/v2/customer-protocol-v2.0。当前程序仍V2，新控制仅设计。

## 采用的方案

客户面对一个Modbus TCP Server/RTU从站，读数据、单字写指令即受理、查状态/错误。厂家负责网关配置及编号与罐号对应。文档[12](12_客户通讯协议V3.md)统一读取和控制；[14](14_简易控制内部设计与状态机.md)只给内部开发，不能当第二本客户册。控制区新分配每台12字；读区不用重排，避免已有组态重新调整。

## 取舍与明确限制

独立停止是正常动作忙时可用的入口，仍有授权与回读；它不是硬急停。结果不确定经人工现场核查、上位机留档后可向原寄存器写0；禁止自动复位和重发，重启不自动重放。正常、停止两个结果保留，不能用停止成功掩盖旧未知。

简易指令提交缺少客户序号，因此每台约定一个控制方、串行请求、复位前停止旧重试；同周期持久化去重有效，跨周期迟到旧写不能无条件识别。若将来要求多控制方竞争或跨周期精确一次，须另外设计所有权/序号，不声称本方案已解决。

不采用新增6字/8字客户测量块，也不做IFX全点表兼容；现有两条96字已满足常用批量读取。普通参数修改和目标定位另行确认。隐藏内部诊断文档不等于权限隔离。

## 交付与实现状态

目标协议版本V3，客户文档V3.0-D2（设计稿）；当前0.2.0/V2不支持简易控制。历史V2资料包保留；旧导出工具因固定分册路径暂停，新交付工具需随V3实现更新并检查白名单。实现后先软件回归和实机验收，再发布新运行包与填写完成的单份客户协议。

D2减少一个客户正常控制点，提交/查询/复位都可用常见单寄存器操作；网关仍承担事务、冻结目标与恢复。并非取消去重/不确定处理。D1指令加触发草案撤回，状态/错误位置迁移，尚无D1运行版本需兼容。
